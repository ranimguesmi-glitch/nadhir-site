# NADHIR · Smart Monitoring System

Landing page for Nadhir, a project of IEEE ENSI Student Branch (https://ensi.ieee.tn).
Nadhir monitors transformer substations (dials, alarm lamps, siren) and alerts the right people before a failure.

## Run
Open `index.html` in a browser, or in VS Code use the **Live Server** extension (right click on `index.html` > Open with Live Server).

## Files
- `index.html`: page structure (Home, About, Our Solution, Demo, Our Values, Our Team, Partners, Contact)
- `style.css`: styles. Brand colors are variables in `:root` (Deep Navy #0B1F3A, Soft Ivory #F4F1E8, Muted Sky #6EA9D9, Warm Amber #D99A32, Slate Blue #526983). Dark mode is automatic.
- `script.js`: team members (`var T`), interactive demo scenarios (`var S`), contact form

## Graphic charter
Fonts: Cormorant SC (titles), Manrope (body). Tagline: "Monitor. Predict. Prevent."
